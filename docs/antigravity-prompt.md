# অ্যান্টিগ্র্যাভিটিতে (বা অন্য AI-তে) দেওয়ার প্রম্পট

নিচের লেখাটুকু কপি করে AI-কে দিন। শুধু পাঠ নম্বরটা বদলাবেন।

---

```
এই প্রজেক্টে "এসো আরবী শিখি" অ্যাপের দারস (পাঠ) বানাতে হবে।

প্রথমে এই দুটি ফাইল পুরোটা পড়ো:
1. docs/dars-build-guide.md   — কাজের সব নিয়ম, ধাপ ও পরীক্ষার পদ্ধতি
2. scripts/book_lessons/vol1-ch1-l3.cjs — সর্বশেষ বানানো দারসের নমুনা

তারপর ঠিক ওই নিয়মে পাঠ ৪ (বই পৃষ্ঠা ২৯–৩৩ = PDF পৃষ্ঠা ২৭–৩১) বানাও।

মনে রাখবে:
- শুধু কিতাবের কনটেন্ট, কিতাবের ক্রমে, সব আরবিতে পূর্ণ হরকত
- প্রতি পর্বে ৬–১৪ ধাপ; পরিচয় কার্ডের চেয়ে চর্চা বেশি; ২–৩টা পর্ব পরপর আলাদা "চর্চা" পর্ব
- লেখার প্রশ্নে সর্বোচ্চ ৩টি অপশন, ছবির প্রশ্নে ৪টি
- ছবি লাগলে src/components/BookPicture.jsx-এ নতুন ৩D SVG আঁকো; কোনো প্রাণীর ছবি নয়
- ১–৩টি ক্বায়েদা খসড়া লিখবে, রিপোর্টে বলবে যে উস্তাদের যাচাই বাকি
- শেষে: node scripts/apply_book_lessons.cjs && npx vite build
- এরপর ব্রাউজারে docs/lesson-autoplay.js দিয়ে প্রতিটি পর্ব খেলে দেখবে (আগে localStorage ব্যাকআপ, পরে রিস্টোর)
- আমাকে বাংলায় রিপোর্ট দেবে; বললে ছাড়া কমিট বা ডিপ্লয় করবে না
```

## পরের পাঠগুলোর পৃষ্ঠা

| পাঠ | বইয়ের পৃষ্ঠা | PDF পৃষ্ঠা | বিষয় |
|---|---|---|---|
| ৪ | ২৯–৩৩ | ২৭–৩১ | اَلْ, চান্দ্র-সৌর হরফ, كَيْفَ؟, নতুন বিশেষণ |
| ৫ | ৩৪–৩৭ | ৩২–৩৫ | كِتَابِي / كِتَابُكَ / كِتَابُهُ, পরিবারের শব্দ |
| ৬ | ৩৮–৪০ | ৩৬–৩৮ | ইযাফত: كِتَابُ رَاشِدٍ, بَابُ الْمَسْجِدِ |
| ৭ | ৪১–৪৪ | ৩৯–৪২ | عِنْدَ / أَمَامَ / فَوْقَ / تَحْتَ, أَيْنَ؟ |

## দরকারি কমান্ড

```bash
node scripts/render_book_pages.mjs _book_compare 27 31 1.6   # কিতাবের পৃষ্ঠা ছবি করা
node scripts/apply_book_lessons.cjs vol1-ch1-l4              # কনটেন্ট বসানো
npx vite build                                               # বিল্ড পরীক্ষা
npm run dev                                                  # ব্রাউজারে দেখা
```

## নতুন দারস ফাইল শুরু করা

`scripts/book_lessons/_TEMPLATE.cjs.txt` কপি করে নাম দিন `vol1-ch1-l4.cjs`, ভেতরের `lN-` গুলো `l4-` করুন।
